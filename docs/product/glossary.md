# Glossaire métier — à valider

| Terme | Définition provisoire | Validation |
|---|---|---|
| Producteur | Personne qui produit des biens agricoles | Valider |
| Ménage | ensemble des personnes vivant sous le même toit que le producteur et partageant les repas ; peut inclure des personnes non apparentées | Valider |
| Exploitation | Unité de production agricole liée à un ou plusieurs producteurs | Valider |
| Parcelle | Surface géographique rattachée à une exploitation, surface sur laquelle on cultive un produit (ex cacao,anacarde, etc..) | Valider |
| Collecte | Opération métier d'enregistrement et saisie des données dans l'application  | Valider |
| Lot | Quantité de produit identifiée et suivie de façon continue dans la chaîne, depuis sa création jusqu'à sa sortie. Un lot est immuable dans son identité ; ses regroupements créent de nouveaux lots | Valider |
| Lot de bord-champ | Lot créé au moment de la pré-collecte sur la parcelle. C'est le lot racine de la chaîne de traçabilité. | Valider |
| Pré-collecte | Opération de collecte réalisée au bord du champ, produisant un lot de bord-champ. | Valider |
| Lot d'évacuation | Lot formé par le regroupement de plusieurs lots de bord-champ d'une même section, lors de l'évacuation vers la section. | Valider |
| Évacuation | Opération de transport des lots de bord-champ vers la section, produisant un lot d'évacuation. | Valider |
| Lot de réception coopérative | Lot formé par le regroupement de plusieurs lots d'évacuation d'une même section à la réception en coopérative. | Valider |
| Réception coopérative | Opération d'entrée des lots d'évacuation dans la coopérative, produisant un lot de réception coopérative. | Valider |
| Lot de transfert exportateur | Lot formé par le regroupement de plusieurs lots de réception coopérative, destiné à l'exportateur. | Valider |
| Transfert exportateur | Opération de sortie des lots de la coopérative vers l'exportateur, produisant un lot de transfert exportateur. | Valider |
| Regroupement | Opération qui consiste à créer un nouveau lot à partir de plusieurs lots existants. Le nouveau lot référence les lots d'origine (traçabilité amont conservée). | Valider |
| Section | Zone géographique et organisationnelle regroupant des producteurs et des lots de bord-champ, servant d'unité d'évacuation. | Valider |
| Événement de traçabilité | Enregistrement daté décrivant une opération (pré-collecte, évacuation, réception, transfert, regroupement) liée à un ou plusieurs lots. | Valider |
| Agent de terrain | Utilisateur réalisant des opérations sur le terrain | À valider |
| Collecteur | Agent de saisie dans les coopératives ; l'un des 3 profils de découverte | À valider |
| Synchronisation | Échange de données locales et serveur, avec traitement des erreurs et conflits | À spécifier |
| Hors ligne | Fonctionnement de certaines fonctions sans accès réseau ; parcours à définir | À spécifier |
| Organisation | Entité cliente qui regroupe des acteurs et des données, avec cloisonnement ; hiérarchie à trancher (Client → Organisation → Coopérative → Campagne → Zone) |À clarifier |
| Coopérative | Structure regroupant des producteurs, réceptacle des lots d'évacuation |À clarifier |
| Campagne | Cycle de production agricole (période) lié a la filière; niveau de hiérarchie à préciser |À clarifier |
| Client | Entité qui contracte avec le fournisseur du SaaS ; distinct de l'Organisation |À clarifier |
| Filière | Filière agricole (cacao, café, anacarde, hévéa, palmier à huile…) |À valider |
| Traçabilité | Capacité à remonter la chaîne de lots, de la parcelle à l'exportateur, via les événements de traçabilité |À valider |
| Durabilité | Critères et certification de durabilité ; référentiels à préciser |À clarifier |
| Blockchain | Technologie d'infalsifiabilité envisagée pour la traçabilité ; décision non prise|À clarifier |
| Rôle | Ensemble de responsabilités attribuées à un profil (ex. collecteur)|À spécifier  |
| Permission | Droit d'effectuer une action donnée, vérifié côté serveur|À spécifier  |
