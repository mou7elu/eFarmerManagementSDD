## Décisions de cadrage confirmées — 2026-10-25
- Pays de lancement : Côte d’Ivoire uniquement.
- Plusieurs filières à étudier dès le départ.
- Livraison : MVP puis extensions.
- Profils à considérer au lancement : producteurs, collecteurs, administrateurs et agents de terrain.
- Plateformes : web et mobile Flutter.
- Mode hors ligne : saisir, consulter et modifier les données déjà téléchargées.
- Multi-organisation avec cloisonnement des données.
- Ambition de volumétrie : environ 800 000 producteurs ou davantage.
- Hébergement à comparer ; aucun fournisseur ni stack n’est approuvé par cette décision.
- Le MVP doit être priorisé après étude de l’ensemble des modules ; tous les modules ne sont pas automatiquement dans le MVP.
